# R1 · Critic: Provocateur (Shklovsky)

**Anchor used:** *Art as Technique* (Shklovsky): habit devours things; the device must make perception difficult and long so the stone is felt as stony. Repainting a familiar device does not estrange it.

**Observed:** index_html-desk.png against site-repo/panel/R2/index_html-desk.png. Beige and orange become an ultramarine ground (#2330d6), an acid-yellow frame (#e4ff3a) and seven spines in seven hues. In Signal the miniatures stay near-white (#fffdf8), almost the old paper. Riso, Cobalt and Mint recolour only the miniatures; the chrome around them does not move. Only Cobalt makes the frame read as one strange object, and it is the third button.

**Findings:**
- F1 [claim] The ground is a real jolt: blue where beige was. Habit breaks at first glance.
- F2 [defect] Seven equal, saturated spine hues make a category legend (the habitual dev-tool palette). When every group shouts, none does.
- F3 [defect] The strangest device is buried. Recolouring all 18 parts at once happens inside small cards while the ultramarine chrome stays still, so the switch feels like a swatch picker.
- F4 [defect] Signal, the default, gives the parts the old cream. The product, the 18 parts, is still the beige site inside a blue box.
- F5 [premise] The brief holds the design fixed, so colour has to carry the estrangement by itself. Colour that only decorates the frame cannot do that.

**Verdict:** OBJECT

**Requested change:**
- F1: none.
- F2: rank the hues. Give one group the acid yellow and set the rest close to the ground, so the spines become a contrast instead of a rainbow.
- F3: let the theme buttons recolour the frame and the ground too, so the whole object changes.
- F4: give Signal a coloured ground for the parts, not paper.
- F5: none.
